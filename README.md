# 🎓 Student Performance Classifier and Analysis

## 📌 Overview
This project explores student performance data using **Machine Learning** and **Data Visualization**.  
The objective is to classify whether a student will **Pass or Fail** based on academic and behavioral factors, and to analyze the key drivers of performance.

## 🚀 Features
- **Data Preprocessing**: cleaning, handling missing values, encoding categorical features.
- **Exploratory Data Analysis (EDA)**: performed in Jupyter Notebook with Python libraries.
- **Machine Learning Models**:
  - Logistic Regression
  - Random Forest
  - XGBoost
- **Evaluation Metrics**: accuracy, confusion matrix, classification report.
- **Feature Importance**: identifying the most influential predictors.
- **Power BI Dashboard**:
  - Interactive visualizations
  - Custom measures (e.g., pass rate, average study hours, attendance impact)
  - Drill-down analysis for deeper insights

## 🛠️ Tech Stack
- **Python 3.9+**
- **Jupyter Notebook or Google Colab**
- **Pandas, NumPy** for data handling
- **Matplotlib, Seaborn** for visualization
- **Scikit-learn** for ML models
- **XGBoost** for gradient boosting
- **Power BI** for interactive dashboards


## 📊 Results
- Logistic Regression: 80% accuracy  
- Random Forest: ~75% accuracy  
- XGBoost: ~75% accuracy
- Decision Trees: 85% accuracy

## 🔮 Future Work
- Hyperparameter tuning with GridSearchCV / RandomizedSearchCV.  
- Adding socio-economic and extracurricular features.  
- Deploying the best model with FastAPI or Streamlit for interactive prediction.
