# 🎓 Student Performance Classifier and Analysis

## 📌 Overview
This project applies **Machine Learning algorithms** to analyze student performance data and predict academic outcomes.  
The aim is to identify key factors (study hours, attendance, previous marks, assignments, backlogs, internet access, etc.) that influence whether a student passes or fails.

## 🚀 Features
- Data preprocessing: cleaning, handling missing values, encoding categorical features.
- Exploratory Data Analysis (EDA) with **Matplotlib** and **Seaborn**.
- Bivariate and multivariate analysis of performance factors.
- Classification models implemented:
  - Logistic Regression
  - Random Forest
  - XGBoost
- Model evaluation with accuracy, confusion matrix, and classification report.
- Feature importance visualization to highlight the most influential predictors.

## 🛠️ Tech Stack
- **Python 3.9+**
- **Pandas** for data handling
- **Matplotlib & Seaborn** for visualization
- **Scikit-learn** for ML models
- **XGBoost** for gradient boosting
